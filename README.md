# IP Theft Through Social Engineering

## Executive Cybersecurity Presentation

This repository contains a team-based executive cybersecurity presentation delivered to a cybersecurity board. The project examines a simulated intellectual-property theft scenario involving social engineering, credential phishing, multifactor authentication (MFA) push fatigue, and unauthorized access to sensitive university research.

## Scenario Overview

In the simulated scenario, a threat actor poses as a legitimate researcher and directs a victim to a fraudulent academic-journal login page. Reused credentials allow the attacker to initiate a login, while a spoofed message convinces the victim to approve an unexpected MFA request. The attacker then uses the compromised account to access sensitive research and intellectual property.
